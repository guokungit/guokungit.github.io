    AI漫剧 0-1 落地手册（精简版）

    MD格式，适合笔记/知识库导入

    1. 什么是AI漫剧

    一句话：基于剧本，AI生成漫画风静态画面，再添加微动、配音字幕、BGM，做成短视频剧集。

    • 不是纯漫画，也不是完整动画；依靠漫画画面+镜头微动+配音营造追剧感
    • 热门题材：重生、穿越、霸总、古风、悬疑
    • 分发平台：抖音、快手、视频号、红果短剧
    • ✅正确流程：写剧本 → 锁定角色 → 生成分镜图 → 图生视频 → 配音剪辑 → 发布
    • ❌误区：不是直接文生视频，随机性大，容易崩脸

    2. 收益与成本

    收入渠道

    1. 平台分成：抖音中视频（横屏≥1min，万播收益低，门槛1万粉）；快手（500粉实名）；百万播放分成约2000-5000元。
    2. 接单代工：按分钟报价。量产组 500-1000元/分钟；成熟团队 2000-5000元/分钟，现金流稳定。
    3. 付费发行：红果短剧、腾讯漫剧，个人可入驻，支持单集付费。
    4. 进阶：账号起量后卖教程。

    成本

    • 新手：免费额度 + 剪映，几乎零成本
    • 长期：即梦AI会员几十元/月
    • 最大成本：试错时间

    ⚠️提醒：万播收益大幅缩水，很难单靠分成暴富，推荐组合：接单代工 + 自有IP。不要幻想躺赚。

    3. 第一步：写分镜剧本（基础）

    单镜头6要素：镜号(阿拉伯数字)、画面内容、人物动作、台词、时长、运镜

    工具

    • 豆包 / DeepSeek：免费写脚本
    • Kimi：适合长篇小说文本处理

    参考Prompt

    规格建议

    • 1~2分钟试水片：30-40镜（新手优先）
    • 3分钟剧集：60-80镜
    • 5分钟剧集：80-120镜

    避坑

    1. 单集剧情不要塞太多事件
    2. 台词精简，优先画面表达
    3. 单镜头≥3秒，镜头不要切太碎
    4. 镜号必须阿拉伯数字，即梦批量导入只识别数字

    4. 第二步：锁定角色（核心难点，防变脸）

    AI漫剧最大翻车点：角色五官前后不一致，观众容易出戏

    1. 生成角色基准图，详细描述五官、发型、服饰，满意后保存；可做多角度参考图
    2. 在即梦保存角色档案，拿到角色ID；生图上传基准图，开启人物参考，权重 0.7~0.8
      • 权重太高画面僵硬；太低锁不住人脸
    3. 提示词首尾固定：开头+结尾重复角色特征，中间写场景剧情
    4. 多角色：每个主角单独文件夹存放基准图；戏份少配角可省略基准图

    Seed值：仅统一画风光影，不能锁定人脸，锁脸依靠基准图+人物参考开关。

    避坑：基准图不要将就；生图记得上传参考图；剧本内统一角色服装外貌设定。

    5. 第三步：生成分镜静态图（地基）

    核心原则：先静态图全部验收合格，再做动态；禁止直接文生视频

    工具选型

    • 即梦AI（新手首选）：角色锁定、批量生图，支持导出剪映工程
    • Midjourney：画质强，付费，英文提示词，锁角色麻烦
    • Stable Diffusion：本地免费，高自由度，需要8G+显存显卡，门槛高

    即梦操作要点

    1. 选定漫画画风，上传角色基准图，开启人物参考
    2. 提示词模板：【角色固定描述】 + 场景画面 + 结尾重申角色不变，漫画高清
    3. 合格图片标准：角色五官匹配基准图、场景符合剧本、构图主体清晰

    场景统一：给每个场景写固定描述模板，每次生图复用，避免场景跳变。

    避坑：固定画风关键词；畸形人物直接重绘，不要强行使用。

    6. 第四步：图生视频，添加微动

    只做轻微动态：眨眼、发丝飘动、衣袖摆动、缓慢推拉镜头；大幅度动作极易崩脸撕裂

    工具

    • 即梦Seedance2.0（首选）：角色稳定，和即梦生图打通
    • 可灵AI：对话场景，口型同步效果更好，角色一致性略差
    • Runway：海外工具，付费，国内访问不便

    操作要点

    1. 上传静态分镜图，填写运动描述：人物微动作 + 镜头运镜 + 环境微动
    2. 单段时长3~5秒，分辨率720P/1080P
    3. 运动幅度选轻微；运镜只用缓慢推拉，禁用快速摇镜、旋转
    4. 台词镜头开启唇形同步；口型效果差可用远景/侧面镜头规避

    Seed值统一整套视频光影画风；相邻镜头运镜反差不要过大。

    7. 第五步：配音 + 剪映剪辑，导出成片

    配音

    • 首选：剪映内置TTS，免费，不同角色分配不同音色
    • 备选：豆包TTS，情感表现力更强
    • 语速：200~220字/分钟，台词合理停顿
    • 建议：新手全集AI配音；高潮情绪镜头可单独真人配音

    剪映流程

    1. 导入视频片段（即梦工程可直接打开自动排序）
    2. 按分镜顺序拼接裁剪
    3. 识别字幕，逐帧校对错别字；字幕放画面下方，避开人脸
    4. 转场只用0.2s叠化/淡入淡出，禁用花哨特效
    5. BGM/音效：剪映可商用素材；BGM音量为人声的20%-30%
    6. 导出：竖屏9:16 / 横屏16:9；1080P，30fps，高码率 MP4

    避坑：字幕错别字、BGM盖过人声、音画不同步。

    8. 发布 & 变现策略

    1. 自有账号拿平台分成：长期积累IP，周期长
    2. 接单代工：现金流稳定，适合稳定产出
    3. 平台付费发行：红果、腾讯漫剧，个人可入驻
    4. 高阶玩法：账号起量后做教学培训

    ✅新手路线：先用免费额度做1分钟小样，跑通完整制作+发布闭环，再接单/做付费剧集。

    9. 版权红线（触碰直接白做）

    1. 网文改编：无原著授权不能商用改编；优先原创剧本或公版故事
    2. 肖像权：禁止生成明星、真人面孔，三分相似也存在侵权风险
    3. 素材版权：BGM、音效、字体必须确认可商用
    4. AI标识：按平台要求片头标注AI生成内容

    重点：AI生成 ≠ 自动拥有著作权，商用前仔细阅读工具用户协议。

    总结

    AI漫剧难点不在于工具操作，核心是 角色一致性 + 版权合规。
    新手建议：先用免费工具制作1分钟小样跑完全流程，评估后再持续投入。
